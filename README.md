# Finance-Loan-Portfolio-Analysis
A Power BI dashboard for analyzing a financial loan portfolio, tracking loan disbursement, EMI collections, outstanding loans, NPA ratio, CIBIL scores, and risk ratios across branch and employee performance. Includes DAX measures, dimension tables, and year/quarter slicers.
# Tools & Technologies Used
Power BI Desktop, Power BI Service (Cloud), SSMS, DAX (Data Analysis Expressions), Custom Visuals (tCard, ChicletSlicer)
# KPI's
**Overview**
Total Loan Disbursed (Cr)
Total Outstanding Loan (Cr)
Total EMI Collected (Cr)
Active Loans
Average Interest Rate
NPA %

**Branch Analysis**
Top Branch by Loan Disbursed
Avg Loan per Branch
Avg Loan per Branch Disbursed
Total Branch Count

**Employee**
Employee Count
Average Loan by Employee (Cr)
Risky Loan Ratio %
CIBIL per Crore Disbursed

# Final Conclusion 
This Power BI dashboard provides a comprehensive view of a financial loan portfolio, enabling data-driven decisions across loan management, branch performance, and employee productivity. By centralizing key metrics like NPA ratio, CIBIL scores and loan disbursement into a single interactive report, it helps stakeholders quickly identify risks, top-performing branches and employee efficiency — supporting better lending and operational strategies.
